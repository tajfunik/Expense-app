# Ďalší plán učenia Reactu

## 1. Custom Hooks ⭐

Cieľ:
Naučiť sa oddeľovať logiku od komponentov.

Naučiť sa:

* vytvoriť vlastný hook
* presunúť logiku mimo JSX
* znovupoužiť logiku medzi komponentmi

Príklad:

* useExpenses()
* useFetch()
* useForm()

---

## 2. useEffect a práca so side effects

Cieľ:
Dobre pochopiť načítavanie a synchronizáciu dát.

Naučiť sa:

* useEffect
* dependency array
* načítanie dát po otvorení stránky
* aktualizácia dát po zmene state
* cleanup funkcie

---

## 3. State management

Cieľ:
Vedieť pracovať s dátami vo väčšej aplikácii.

Naučiť sa:

### Context API

* globálny state
* odstránenie prop drilling

### Zustand alebo Redux Toolkit

* komplexnejší state management
* oddelenie logiky aplikácie

---

## 4. React Router

Cieľ:
Vytvoriť aplikáciu s viacerými stránkami.

Naučiť sa:

* routing
* dynamické URL
* parametre stránky
* navigácia

Príklad:

/dashboard
/expenses
/expenses/:id
/settings

---

## 5. Formuláre a validácia

Cieľ:
Vedieť vytvárať profesionálne formuláre.

Naučiť sa:

* controlled vs uncontrolled inputs
* validácia formulára
* error messages
* React Hook Form
* Zod/Yup
